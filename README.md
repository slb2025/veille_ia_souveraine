# veille_ia_souveraine
Pipeline de veille technologique souverain et local (ETL + RAG) sous Windows/WSL2 optimisé pour architecture unifiée AMD Ryzen AI 9. Confinement strict 127.0.0.1, coût d'exploitation 0 €, typage statique absolu (Mypy strict sans Any) et persistance native sur volumes Docker nommés.
